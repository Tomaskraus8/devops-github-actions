### 1. Lokální prostředí (Windows / Linux / macOS)

Nainstaluj balíčkovač podle svého operačního systému:

- **macOS** — [Homebrew](https://brew.sh/)
  ```bash
  brew --version
  ```
- **Windows** — [Chocolatey](https://chocolatey.org/install)
- **Ubuntu / Debian** — `apt`
- **CentOS / RedHat** — `yum` / `dnf`

Dále nainstaluj textový editor, ideálně [Visual Studio Code](https://code.visualstudio.com/).
